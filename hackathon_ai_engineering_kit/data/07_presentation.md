# Защита решения

Защита проходит в формате презентации. В защите может участвовать любое количество членов команды.

На защиту решения каждой команде отводится 7 минут.

После защиты члены ГСК могут задать не более 2–3 вопросов. На ответ по каждому вопросу отводится не более 2 минут.

Во время защиты команда по своему усмотрению может использовать раздаточные материалы, слайды, демонстрацию экрана компьютера, планшета или мобильного телефона.

Одна команда может представить на защите только один результат.

В презентации должны быть указаны:
- решаемое кейсовое задание с бизнес-постановкой;
- шаги решения задачи;
- архитектурное решение;
- презентация результата работы приложения, сервиса или программы в формате видеоролика длительностью не более 2 минут.

Презентация оценивается по четырём критериям: соответствие структуре, презентация функционирующего прототипа, раскрытие сущности проекта и качество публичного выступления.
