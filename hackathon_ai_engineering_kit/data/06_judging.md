# Методика и критерии оценки

Результаты оцениваются методом суммирования индивидуальных экспертных оценок членов главной судейской коллегии (ГСК) по заданному перечню критериев.

Критерии оценки:
1. Соответствие технологического решения заявленным в кейсе функциональным требованиям.
2. Работоспособность прототипа.
3. Технологичность.
4. Потенциал презентуемого решения.
5. Презентация.

Каждый критерий оценивается по десятибалльной шкале (от 1 до 10). Итоговый балл команды — сумма баллов по каждому критерию от каждого члена ГСК. Максимальное количество баллов по всем критериям от всех членов ГСК — 50 баллов.

## Критерии кейса Ujin OS

Каждое из пяти направлений даёт до 10 баллов, всего до 50.

Работоспособность прототипа:
- видео-демонстрация продукта — 0–2 балла;
- завершённость: работающий прототип, доступный пользователям и судьям — 0–3 балла;
- дизайн — 0–3 балла;
- удобство интерфейса для всех категорий пользователей — 0–2 балла.

Соответствие функциональным требованиям:
- конструктор устройств — 0–1 балл;
- эмуляторы устройств — 0–2 балла;
- редактор пользовательских сценариев — 0–2 балла;
- исполнение сценариев — 0–2 балла;
- интеграция с платформой Ujin OS — 0–2 балла;
- пользовательский интерфейс и демонстрационные сценарии — 0–1 балл.

Презентация:
- соответствие структуре — 0–2 балла;
- презентация функционирующего прототипа — 0–3 балла;
- раскрытие сущности проекта — 0–3 балла;
- качество публичного выступления — 0–2 балла.

Технологичность:
- работоспособность и качество кода — 0–4 балла;
- использование фреймворков — 0–2 балла;
- использованные технологии (количество, сложность) — 0–4 балла.

Потенциал:
- возможность выхода на рынок в рамках одного года — 0–3 балла;
- ценность проекта (социальная значимость или коммерческая перспективность) — 0–2 балла;
- roadmap проекта — 0–3 балла;
- конкурентные преимущества — 0–2 балла.

## Итоги

Победителями признаются команды, набравшие три наивысших результата по итогам защиты. На спортивные разряды могут претендовать команды, занявшие первые шесть позиций в рейтинговой таблице.

Если несколько команд набрали одинаковое количество баллов, все они признаются победителями. Подведение итогов — в течение 60 минут после завершения защит всех команд.
